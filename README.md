## About

Initially was created to integrate pulseaudio events (such volume changes) into [awesomewm](https://github.com/awesomeWM/awesome). Right now after completed migration to wayland+[hyprland](https://github.com/hyprwm/Hyprland), I've adjusted this project to be able handle hyprland-related events, which previously were emitted by awesomewm.
